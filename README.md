**https://github.com/jude2009419/biq-scanner**

### ✨ Features
- **Port Scanner** - Scan any IP for open ports [21,22,53,80,443,3306,8080]
- **QR Generator** - Turn any link/text into a QR image (qr.png)

### 📦 How to run
```bash
git clone https://github.com/jude2009419/biq-scanner.git
cd biq-scanner
pip install qrcode pillow
python main.py
